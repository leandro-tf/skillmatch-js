#  SkillMatch JS

Projeto desenvolvido para simular a compatibilidade entre um candidato e vagas de emprego na área de Front-End, utilizando JavaScript puro.

---

##  Funcionalidades

- Cadastro de perfil do candidato
- Listagem de vagas
- Cálculo de compatibilidade (%)
- Classificação das vagas (Alta, Média, Baixa)
- Identificação de habilidades encontradas
- Identificação de habilidades faltantes
- Seleção automática da melhor vaga
- Sugestão de estudos

---

##  Conceitos Utilizados

- Arrays
- Objetos
- map()
- filter()
- forEach()
- reduce()
- includes()
- Estruturas condicionais (if/else)
- Template Strings

---

##  Como Executar

1. Instale o Node.js
2. No terminal, acesse a pasta do projeto
3. Execute:

```bash
node skillmatch.js
