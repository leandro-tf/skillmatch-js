# 🚀 SkillMatch JS

Simulador de compatibilidade entre candidato e vagas de emprego na área de Front-End, desenvolvido em JavaScript.

---

## 📌 Descrição

O **SkillMatch JS** é um projeto que analisa o perfil de um candidato e compara suas habilidades com os requisitos de diferentes vagas, retornando o nível de compatibilidade para cada uma.

O sistema também identifica lacunas de conhecimento e sugere quais habilidades devem ser estudadas para aumentar as chances de contratação.

---

## ⚙️ Funcionalidades

* ✔ Cadastro de candidato
* ✔ Cadastro de vagas com requisitos
* ✔ Cálculo de compatibilidade (%)
* ✔ Classificação automática:

  * Alta compatibilidade
  * Média compatibilidade
  * Baixa compatibilidade
* ✔ Identificação de habilidades faltantes
* ✔ Recomendação de estudos
* ✔ Identificação da melhor vaga
* ✔ Listagem de vagas remotas
* ✔ Simulação de busca de dados com async/await
* ✔ Contador de análises com closure

## ▶️ Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/leandro-tf/skillmatch-js.git
```

2. Acesse a pasta do projeto:

```bash
cd skillmatch-js
```

3. Execute o arquivo:

```bash
node skillmatch.js
```
